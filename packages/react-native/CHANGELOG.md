# Changelog

All notable changes to `@brudcast/react-native` are listed here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the package follows
[Semantic Versioning](https://semver.org) with the same version as the native SDKs it runs.

## [0.2.0] - Unreleased

### Added

- `Brudcast.initialize`, `identify`, `reset`, `track`, `screen`, `optOut`, `optIn`,
  `disableTracking`, `enableTracking`, `flush`, `getDeviceId` and `isValidEventName`, over the
  native Android and iOS SDKs 0.2.0.
- `Brudcast.setActionHandler`, which may answer asynchronously within two seconds. A push tap that
  launches the app waits up to five seconds for the handler.
- `localEnvironment` and `customEnvironment` for development and private deployments.
- New Architecture only: a TurboModule generated by codegen. React Native 0.86 and later.
